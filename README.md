# Instructions
1. import [global.css](css/global.css) for every files
2. Add this meta tags to your header:
    ```html
    <link rel="stylesheet" href="./css/global.css">
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    <link href="https://fonts.googleapis.com/css2?family=Inria+Serif:ital,wght@0,300;0,400;0,700;1,300;1,400;1,700&family=Inter:ital,opsz,wght@0,14..32,100..900;1,14..32,100..900&display=swap" rel="stylesheet">
    ```
3. Use header provided in index.html
4. Use this component for unified button styling
    ```html
    <div class="cta-button">
        <a href="#">Explore Programs</a>
        <span class="underline-button"></span>
    </div>
   ```
5. Always follow the font sizing on figma
